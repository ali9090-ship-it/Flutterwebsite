# Kotlin Android Portfolio (Jetpack Compose)

## Open and run
1. Open Android Studio (Koala or newer) -> File -> Open -> select this `kotlin_android` folder.
2. Wait for Gradle sync (Android Studio creates the Gradle wrapper for you).
3. Run on an emulator or a phone.

## Edit your content
Open `app/src/main/java/com/mohdali/portfolio/ui/PortfolioScreen.kt` and change the block at the top.

## Build an APK to share
Build -> Build Bundle(s) / APK(s) -> Build APK(s).
The file is in `app/build/outputs/apk/`. Upload it to GitHub Releases and link it from your website.
